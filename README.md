# Friend Rivals

Плагин для **Beat Saber 1.40.8**: сравнивает ваши скоры на [BeatLeader](https://beatleader.com)
со скорами друга и собирает плейлист из карт, на которых друг вас обыграл.

- Список друзей берётся из вашего аккаунта BeatLeader: аватарки, место в мире и в стране, pp.
- Отдельно логиниться не нужно: плагин использует сессию, которую уже открыл мод BeatLeader.
- Плейлист пополняется постепенно: за одно нажатие добавляется до N самых свежих
  проигранных песен, которых в нём ещё нет.
- Песни, на которых вы уже обогнали друга, из плейлиста убираются автоматически.

## Установка

### 1. Зависимости

Нужны моды ниже. Обычно они уже стоят, если вы ставили BeatLeader через
[BSManager](https://github.com/Zagrios/bs-manager) или [ModAssistant](https://github.com/bsmg/ModAssistant).

| Мод | Версия |
|---|---|
| BSIPA | 4.3+ |
| BeatSaberMarkupLanguage (BSML) | 1.12+ |
| SiraUtil | 3.1+ |
| SongCore | 3.14+ |
| BeatSaberPlaylistsLib | 1.7+ |
| PlaylistManager | 1.7+ (чтобы плейлисты было видно в игре) |
| BeatLeader | 0.10+ |

### 2. Плагин

1. Скачайте `FriendRivals-x.y.z.zip` со страницы [Releases](../../releases).
2. Распакуйте архив в папку игры. Файл должен оказаться по пути
   `Beat Saber\Plugins\FriendRivals.dll`.
   - Steam: `C:\Program Files (x86)\Steam\steamapps\common\Beat Saber`
   - BSManager: `...\BSManager\BSInstances\<имя версии>`
3. Запустите игру.

## Как пользоваться

1. Запустите игру и дождитесь, пока BeatLeader войдёт в аккаунт (как обычно).
2. В главном меню откройте раздел кнопок модов и нажмите **Friend Rivals**.
3. В центре появится список друзей с BeatLeader. Выберите друга.
4. На правом экране выберите ползунком, сколько песен добавить (по умолчанию 50),
   и нажмите **«Обновить плейлист»**.
5. Плейлист **«<Друг> обыграл меня»** появится среди плейлистов в игре.
   Обложка — аватар друга. Если песня не скачана, PlaylistManager предложит её загрузить.

Нажмите **«Обновить плейлист»** ещё раз, когда отыграете добавленные песни:
- песни, где вы уже обогнали друга, уберутся;
- добавятся следующие (по дате скора друга, от новых к старым).

Файл плейлиста: `Playlists\FriendRivals_<id друга>.bplist`.

### Как сравниваются скоры

Сравниваются лидерборды BeatLeader, то есть одна и та же песня в том же режиме
и на той же сложности. Друг считается обыгравшим вас, если его **точность** на этом
лидерборде выше вашей. Точность BeatLeader учитывает модификаторы.

## Частые проблемы

| Проблема | Что делать |
|---|---|
| Нет кнопки Friend Rivals в меню | Проверьте `Logs\_latest.log`: строка `'FriendRivals' is missing dependency ...` укажет, какого мода не хватает |
| «BeatLeader не авторизован» | Убедитесь, что BeatLeader в игре вошёл в аккаунт, и нажмите «Обновить друзей» |
| Список друзей пуст | Добавьте друзей на сайте BeatLeader или в игре через лидерборд BeatLeader |
| Сетевая ошибка | Нажмите «Обновить друзей» ещё раз |

## Сборка из исходников

Нужен [.NET SDK](https://dotnet.microsoft.com/download) 8 или новее и установленная
игра со всеми зависимостями: сборка ссылается на DLL игры и модов.

1. Укажите путь к игре. Если игра стоит не по стандартному пути Steam, создайте рядом
   с проектом файл `FriendRivals/FriendRivals.csproj.user`:

   ```xml
   <Project>
     <PropertyGroup>
       <BeatSaberDir>D:\Games\Beat Saber</BeatSaberDir>
     </PropertyGroup>
   </Project>
   ```

   Путь можно передать и разово: `-p:BeatSaberDir="D:\Games\Beat Saber"`.

2. Соберите:

   ```bash
   dotnet build FriendRivals -c Release
   ```

   После сборки `FriendRivals.dll` автоматически копируется в `Plugins` игры
   (если игра запущена, копирование не пройдёт — закройте её).
   Чтобы не копировать, добавьте `-p:CopyToGame=false`.

### Устройство

| Файл | Назначение |
|---|---|
| `Plugin.cs` | Точка входа BSIPA, регистрирует Zenject-инсталлер для меню |
| `BeatLeader/BeatLeaderSession.cs` | Через reflection берёт `CookieContainer` сессии из `BeatLeader.WebRequests.WebRequestFactory` и адрес API |
| `BeatLeader/BeatLeaderClient.cs` | Запросы: `GET /user` (профиль и друзья), `GET /player/{id}/scores/compact` (все скоры, по 100 за страницу) |
| `RivalPlaylistBuilder.cs` | Сравнение скоров и обновление плейлиста через BeatSaberPlaylistsLib |
| `UI/` | Кнопка в меню, FlowCoordinator, список друзей (центр) и панель действий (справа) |

Авторизация завязана на внутреннее устройство мода BeatLeader (проверено на 0.10.0).
Если в новой версии BeatLeader это поменяется, плагин покажет ошибку в статусе.
